EKHUM - GOOD DESERVES BETTER
Shareable website source package

OPEN THE WEBSITE
Extract the ZIP first, then open index.html in a modern browser.
Keep the assets folder, ekhum.css and ekhum.js beside index.html.
No installation, build command or internet connection is needed.

CONTENTS
index.html: page content and structure
ekhum.css: styling, responsive layouts and animation
ekhum.js: platform tabs, filters, calculator and enquiry interaction
assets/: Indian imagery, supplied organisation logos, Manrope font and licence
IMAGE-SOURCES.txt: image provenance and generation prompts

FEATURES
Four-stage platform explorer with keyboard navigation
Filterable, expandable capability table
Interactive savings calculator
Responsive navigation and reduced-motion support

DEMO ENQUIRIES
This is a static website preview. The enquiry form downloads a local text
brief. It does not transmit personal information, send email or book a demo.
A production enquiry endpoint must be connected before accepting bookings.

IMAGERY AND CLAIMS
The three Indian community images are AI-generated illustrative scenes,
not photographs of Ekhum staff, beneficiaries or actual programmes.
Organisation logos are retained from the user-supplied reference.
Experience figures use the user's supplied 40 organisations and Rs. 1 billion.
The platform fee and features follow the supplied product reference.
The optional payment-recovery estimate assumes 3%, not a guaranteed result.

PRIVACY
The package is local. No public link or deployment has been created.
